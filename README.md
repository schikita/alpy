# «Наш буевский ответ Альпам» — лендинг репортажа «СГ»

Одностраничный креативный лендинг по репортажу «СГ» о козьей сыроварне Ирины
Лужковой в деревне Буево (20 км от Витебска). Открывается просто двойным щелчком
по `index.html` — без сборки, без зависимостей.

## Как смотреть

```
открыть index.html в браузере
```

Всё локально: ни одного внешнего запроса, кроме шрифтов Google Fonts
(Unbounded / Golos Text / JetBrains Mono). Без интернета подхватятся
системные fallback-шрифты, вёрстка и логика сохранятся.

## Структура

Порядок текста повторяет исходный репортаж: h1 «Наш буевский ответ Альпам»,
лид «Как дети асфальта пытались перехитрить породистых коз…», затем текст
блоками по секциям (главы 01–05, продолжения глав помечены `data-parent`).

| Секция | Что в ней |
| --- | --- |
| `#top` | h1, лид, коллаж, печать, счётчики, бегущая строка |
| `#intro` | «Вместо предисловия» — первый абзац репортажа, карточка авторов |
| `#shengen` | 01 / Шенген не нужен: квест за сыром, ферма в Буево, «Милавица», цитата про тумблер |
| `#shengen-2` | 01 · продолжение: «После городской суеты…», «Я человек дотошный», поездка за козами |
| `#shengen-3` | 01 · продолжение: первая банка молока, 11 видов сыра, цитата про четыре желудка, карусель подворья |
| `#vily` | 02 / От вил — к марле: вилы, арсенал, закреплённая сцена (2 остановки) |
| `#vily-2` | 02 · продолжение: Кристина, марля и сыворотка, слайдер «молоко → сыр», карусель смены |
| `#shpargalka` | 03 / Сырная шпаргалка: 5 шагов, термометр, цифры вызревания |
| `#degustacia` | 04 / Дегустация: три сыра, слово эксперта, кинолента, P. S. |
| `#recept` | 05 / Рецепт от шефа: ингредиенты, инструменты, чек-лист из 6 шагов |
| `#galereya` | галерея 50 кадров с фильтрами, лайтбоксом и бегущей строкой |

| Файл | Назначение |
| --- | --- |
| `index.html` | разметка: прелоадер, шапка, круговое меню, рельс, 11 секций, лайтбокс |
| `style.css` | дизайн-токены, темы разделов, раскладка, анимации, адаптив |
| `js/app.js` | весь интерактив: разбивка текста, появления, карусели, галерея, лайтбокс, меню, курсор |
| `js/galleries.js` | подписи и теги 50 кадров, группы разделов, чистые хелперы (filter/wrap/span) |
| `js/photos.js` | сгенерированный манифест кадров (пути, размеры, blur-заглушки) |
| `assets/img/` | исходные фотографии (не изменяются) |
| `assets/img/opt/` | оптимизированные WebP: `-tn` 400px, `-sm` 900px, `-md` 1700px |
| `assets/img/logo.png` | знак «СГ»: 4 квадранта, из которых собран прелоадер и навигация |

`assets/img/` занимает ~170 МБ исходников — страница их не грузит, только `opt/`
(≈10 МБ WebP, из них на первом экране ~150 КБ).

## Инструменты

```bash
python3 tools/build-assets.py    # пересобрать WebP + js/photos.js + контрольные листы
node tools/check-site.js         # 94 статические проверки: данные, ссылки, классы, контраст, текст репортажа, разметка
node tools/smoke-test.js         # рантайм в headless Chrome: что JS действительно собрал страницу
node tools/interaction-test.js   # клики/клавиатура: лайтбокс, меню, фильтры, чек-лист, карусель
python3 tools/make-diag.py flat-2  # временная копия _diag.html для скриншотов разделов
```

Отдельная группа проверок сверяет **52 фрагмента исходного RTF** дословно — если правка
случайно изменит текст репортажа, `check-site` упадёт.

`_diag.html` в корне — временный диагностический файл (пересобирается
`make-diag.py`, можно удалять). `tools/contact/sheet-*.jpg` — контрольные листы
кадров, снятые при сборке ассетов, тоже служебные.

## Дизайн-система

- **Палитра** из логотипа: `#FF1A00` (крафтовый красный), `#0F7611` (выпас),
  `#F6F0E5` молоко, `#E9C86A` сырная головка, `#16110C` чернила.
- **Фото-фон у каждой секции**: `data-bg="NN"` + блок `.sec__bg` с адаптивным
  `<picture>` (900/1700 px) внутри — фон работает и без JS, едет с параллаксом
  и притемняется градиентом `--scrim-hi / --scrim-lo` под текст.
- **Темы разделов** (`data-theme`): молоко → тёмный → красный → сырный → молоко → тёмный.
  Секции красят себя сами, поэтому цвета работают и без JS; `body[data-theme]`
  переключается скроллом для шапки, меню и рельса.
- **Красный не сочетается с белым**: на красном фоне текст всегда чёрный
  (`color: #000`), чипы, бейджи, активные фильтры и бегущая строка — тоже;
  красный *текст* на светлом заменён на `--accent-text` (тёмно-кирпичный),
  на тёмном — на тёплый `#ff6a55`.
- **Шрифты**: Unbounded (дисплей), Golos Text (текст), JetBrains Mono (служебные подписи).
- **Движение**: `cubic-bezier(.16,1,.3,1)` для появлений, `cubic-bezier(.65,.02,.35,1)`
  для переходов тем; микровзаимодействия 0.28 с, разделы 0.9–1.4 с.

## Доступность

- Контраст текста проверяется автотестом (WCAG AA ≥ 4.5:1) — включая худший случай
  «текст поверх самого светлого и самого тёмного кадра» для всех четырёх тем.
- Отдельные проверки: нет правил с белым текстом на красном, выделение текста тёмное
  на красном, у активных чипов и бейджей — тёмный текст.
- `prefers-reduced-motion` снимает анимации и оставляет контент видимым.
- Работает без JS: текст, рецепт, галерея (сокращённая), все фото героя и все фото-фоны.
- Лайтбокс и меню — диалоги с ловушкой фокуса, `Esc`, стрелками; у кадров есть `alt` и кнопки-хиты.
