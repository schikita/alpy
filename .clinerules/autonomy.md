# Autonomy Guidelines

## Free Actions (no confirmation needed)
- Run tests and linters.
- Create or edit files on a feature branch.
- Read any non-sensitive file in the repo.

## Requires Confirmation
- Installing or upgrading dependencies.
- Modifying files on `main` / `master`.
- Deleting files.

## Never Allowed
- Force-pushing to any branch.
- Pushing directly to `main`.
- Exposing secrets in chat or logs.
